# Social Compass

Ik wil een systeem zoals https://checksocials.com, een dashboard app waar je alles bij kunt houden van je socials maar ook posts kunt maken met voorgestelde content. Ook neemt hij daarin concurrentie mee wat goed werkt en kan hij analyses houden. Kan jij een systeem zoals deze site maken?
